<h1 align="center">🐬 GoAzuriom</h1>
<p align="center"><b>GoAzuriom</b> is a simple and efficient Go client for interacting with Azuriom authentication APIs.
Easily verify user credentials and retrieve rich account data with minimal setup!</p>

## 🚀 Installation

To install GoAzuriom, run:
```bash
go get github.com/JustTimmm/GoAzuriom
```

Then import it into your project:
```go
import "github.com/JustTimmm/GoAzuriom/azuriom"
```
